## Approved asset intake

Record asset identifier, creator/owner, original file/source URL, license or permission, date, exact product/SKU/batch association if applicable, intended locale, caption/alternative text, reviewer and version. A photograph of a package does not establish measured content or analytical approval. Keep the original approved file and mark replacement/revocation explicitly.

The first photography request is an authentic front packshot per approved package/variant, then readable label detail and an optional genuine package/closure view. Use consistent neutral background, camera angle, scale and soft lighting. Do not retouch labels into a different SKU, add report/batch claims, or depict unsupported material appearance. Product information and the original records remain primary.
